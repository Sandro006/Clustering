Renseigne les valeurs puis clique sur « Générer » pour remplir l'éditeur. Tu pourras ensuite affiner le texte avant d'appliquer.

Éditeur — haproxy.cfg

Chargement de la configuration…

« Appliquer » sauvegarde l'ancien fichier en haproxy.cfg.bak, valide la syntaxe avec haproxy -c puis redémarre HAProxy via WSL. En cas d'erreur, l'ancienne configuration est restaurée. En mode NAT, host.docker.internal est remplacé automatiquement par l'IP de l'hôte Windows.

Rappel des directives

  • balance : répartition des requêtes (roundrobin, leastconn, source…).
  • server … check : backend avec contrôle de santé automatique.
  • cookie SERVERID insert indirect nocache : attache un client à un serveur.
  • stats uri /stats : tableau de bord sur le port des statistiques.
